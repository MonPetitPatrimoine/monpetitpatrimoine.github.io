Questions

Questions fréquentes

Windows affiche « Windows a protégé votre ordinateur ». Est-ce normal ?

Oui. L’installeur n’est pas signé : un certificat coûte plusieurs centaines d’euros par an. Je préfère garder l’application à petit prix. Cliquez sur « Informations complémentaires », puis « Exécuter quand même ». Si ce bouton n’apparaît pas, le contrôle intelligent des applications de Windows est activé : l’installation n’est alors pas possible sur cet ordinateur.

Où sont mes données ?

Uniquement sur votre ordinateur, dans un fichier, avec une sauvegarde automatique à chaque modification dans le dossier de votre choix (30 jours de sauvegarde gardés). Aucun compte, aucun identifiant bancaire, aucun serveur.

L’application se connecte-t-elle à Internet ?

Seulement pour deux choses. D’abord obtenir les cours de vos fonds : seul leur code ISIN est demandé, jamais un montant ni votre nom. Ensuite vérifier s’il existe une nouvelle version. Vous pouvez désactiver la seconde.

Fonctionne-t-elle avec ma banque ?

Oui, avec toutes les banques et tous les courtiers : vous saisissez vos lignes et vos soldes, ou vos positions actuelles au démarrage. L’import automatique de l’historique est réservé, pour l’instant, aux clients Fortuneo.

C’est quoi, le code ISIN ?

Un code de 12 caractères qui identifie chaque fonds ou action, par exemple FR0011550185. Vous le trouvez sur votre relevé ou sur la fiche du fonds chez votre banque. Il permet à l’application de suivre les cours tout seule.

Que se passe-t-il après les 30 jours ?

Sans licence, l’application passe en lecture seule : vous voyez toujours vos chiffres et pouvez tout exporter. Seule la saisie s’arrête.

Comment activer ma licence ?

Après l’achat, vous recevez une clé par e-mail. Dans l’application : Réglages généraux → Licence → collez la clé → Activer. Pas besoin de redémarrer.

Et si je change d’ordinateur ?

Sur l’ancien ordinateur : Réglages généraux → « Exporter tous les comptes ». Sur le nouveau : installez l’application, puis « Restaurer un fichier » et collez votre clé.

Puis-je l’utiliser sur plusieurs ordinateurs ?

Oui, sur tous vos ordinateurs personnels. Une licence = une personne : chaque membre du foyer qui suit son propre patrimoine prend la sienne.

Est-ce un conseil financier ?

Non. L’application vous montre où vous en êtes ; les décisions restent les vôtres. Les calculs sont des estimations, à rapprocher de vos documents officiels.

Sur Mac ou téléphone ?

Pas pour l’instant : Windows 10 et 11 (64 bits) seulement.
